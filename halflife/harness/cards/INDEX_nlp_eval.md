## Patterns

1. "gpt-4-turbo" is an alias false positive in 6 of 7 papers: the phrase denotes gpt-4-1106-preview or gpt-4-0125-preview (both dead 2026-03-26); only ReviewCritique used the alias after the 2024-04-09 GA release, so only it has a genuine live baseline.
2. Two papers (SAD, Judgement Bias) nevertheless contain a dying arm — undated alias "gpt-4o" run in June 2024 = gpt-4o-2024-05-13 — recoverable only via run-date forensics (evalresult filenames, access-time table); both need user approval to swap arms.
3. Artifacts split cleanly: judge/annotator-style papers with repos (AlpacaEval, SAD, Judgement Bias, ReviewCritique) ship data and often cached raw model outputs, but almost none ship the judge prompt as a file, decoding parameters, or the evaluation/aggregation script; the two Microsoft papers (distributional, prompt-formatting) released nothing at all.
