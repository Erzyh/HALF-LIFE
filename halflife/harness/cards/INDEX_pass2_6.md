## Notes from this batch

1. **Repositories settled two of the three open prompt questions.** The Tier B triage for W4404781910 could not tell which template the proprietary baseline received (the paper only says each model used "its original prompt template"); `config/gpt-4o.yaml` answers it — `prompt: llmbar`, temperature 0, max_tokens 20. For W4400103831 the paper prints only the openings of the generation and G-Eval prompts; the repository has all twelve prompt files plus the 10 identified ShuttleSet matches. Both cards are therefore upgrades from prompt-level replay to repository-based re-execution. W7150802891 has no repository at all, so no upgrade is available and the card differs from the existing Tier B config only in pinning the CIDEr-D scorer, fixing the exemplar-draw seed and correcting the cost (the config's $60 implicitly assumed low-detail image tokens).
2. **Released outputs are not always the published numbers.** BADGE ships all 170 reports and all 680 judge outputs. Re-aggregating them without any API call reproduces the Table 2 human row (7.933 vs 7.925) and GPT-3.5 row (8.625 exactly) but gives 8.40 for the GPT-4 row instead of 8.825 — two released consistency judgements for GPT-4 reports are 3 and 4, and one file has no score at all. With temperature unset (1.0) and n = 10 matches, the 0.20 gap that carries the paper's writer-ranking claim is inside plausible judge noise.
3. **Snapshot dating was exact in three of four papers**, with no alias inference needed: gpt-4o-2024-05-13 (×2), gpt-4-turbo-2024-04-09, and the two NeuroScape mentions (gpt-4o-2024-08-06, o1-2024-12-17). The census caveat in this batch is not aliasing but *role*: W7131889008's only retiring snapshot appears solely in the AI-use declaration, and W7150802891's live arm appears in one table row of a paper whose other rows are dead or open-weight models.
4. **Image inputs remain the hard wall.** W7150802891 is the batch's only vision paper and is blocked on three independent grounds (text-only runner, ~$100 for the single seed the authors themselves ran, human-gated 1.5 GB CC BY-NC download) — the first Tier A card where the metric tooling (pycocoevalcap, with a JVM for SPICE) would also have to be rebuilt from third-party code.
