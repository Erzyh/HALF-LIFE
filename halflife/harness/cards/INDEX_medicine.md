## Common patterns

1. **"gpt-4-turbo" is mostly an alias false positive.** Only 4/11 papers name a still-callable dated snapshot (o1-2024-12-17, gpt-4-turbo-2024-04-09, gpt-4o-2024-05-13, gpt-4.1-nano-2025-04-14); in the others the real arm was a dead preview snapshot (gpt-4-0125-preview ×2), a consumer web product (ChatGPT/Bing ×2), or a citation of prior work (×1) — so the census must down-weight alias-only matches.
2. **Data, not code, is the wall.** Prompts and evaluation scripts exist for 8/11, but licensed/confidential items (JAMA, StatPearls, AMBOSS, instructor exams, UW notes, copyrighted PDFs/full texts) block or partially block 8/11; two authors' "data available" pointers (a 404 GitHub repo, on-request spreadsheets) do not deliver.
3. **Generation settings are under- or mis-reported.** Temperature/max_tokens are unreported or web-default in 5/11, and two papers describe settings the API cannot honour (o1 at temperature 0.3; max_tokens=1 with a "reason step-by-step" prompt) — ANALYSIS_PLAN §3's "temperature 0 when unreported" rule and a "protocol artifact" flag will both be needed.
