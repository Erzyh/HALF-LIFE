## Common patterns

1. **The repository decides the tier, not the paper.** Two of four repositories are close enough to the paper to support a genuine repository-based re-execution (TAMA's seeded data-processing and offline scorers; ING-VP's complete engines, solvers, prompts and 300 levels). One is a data-and-README drop with no code whatsoever (Neptune), and one is a refactored "framework" whose math path points at a different dataset, a different prompt and a token limit the API rejects for reasoning models (InterlocutorAwarenessLLM). For the last of these the existing Tier B prompt-level config is *closer to the paper* than the authors' own scripts, so the repository is best used to pin the snapshot and the scorer rather than as the execution path.
2. **Vision papers are not automatically blocked — check which cells the live arm actually occupies.** ING-VP looks like a multimodal benchmark, but GPT-4 Turbo's three image-text cells in Table 1 are `null`: it was evaluated text-only, with ASCII boards and JSON position lists, which fits the text-only runner exactly. Neptune goes the other way — the multimodal path is unavoidable *and* the authors shipped no code to lean on, so it fails the "paper's own code handles it" test and the ~$166-per-seed test at once.
3. **Released code carries silent bugs that shaped the published tables, and the tables show their fingerprints.** ING-VP's multi-step text path freezes the board after step 1 and resolves the history placeholder to an empty string, which makes the with-history and without-history conditions the same experiment — and both GPT-4 Turbo and Claude-3 Opus have byte-identical accuracies in those two rows (2.30 / 2.30). TAMA's `aitqa.py` credits GPT prediction folders twice for an exact match while scoring its own checkpoints strictly. Neither is fatal, but both must be decided explicitly: reproduce verbatim (replication) or repair (labelled variant).
4. **Heatmap cells need panel-by-panel reading.** The Tier B config for W4416035547 recorded the o4-mini self-identification Math accuracy as 0.93; reading Figure 11's six panels in order gives 0.64 for Math — 0.93 is the same cell in the XSum and UltraChat panels, and Figure 9(a) is a family-level F1 heatmap (GPT × GPT = 0.37), not the F1 counterpart of that cell. The card carries the correction and flags it for the user.
5. **Two of four snapshots rest on the date rule.** Only Neptune (footnote 4) and the interlocutor paper (Section 2.3) name a dated snapshot. TAMA's Appendix A.4 says "GPT-4-turbo" with no code to check, and ING-VP's code asks a redacted gateway for `gpt-4-turbo-128k`, which is a proxy alias rather than an OpenAI id — both resolve to gpt-4-turbo-2024-04-09 under the post-2024-07-01 rule, and both carry the inference in `user_checks`.
6. **Benchmark releases drift downward.** Neptune's public annotations now hold 2,974 of the paper's 3,268 questions (91%) and 2,189 of 2,405 videos, so the paper's item count is unattainable even before YouTube attrition. On the other hand its annotations turned out to be freely downloadable after all: the README's `storage.mtls.cloud.google.com` links are sign-in gated, but the plain `storage.googleapis.com/neptunedata/` URLs serve both JSONs anonymously — a correction to the Tier B record.
