## Observations

- **A batch dominated by mention-only and citation padding.** 14 of 31 ineligible papers use `gpt-4-turbo`/`gpt-4.1`/`gpt-5` only in a related-work citation, a design-rationale aside, a writing-assistance disclosure, or a survey/systematic-review summary of someone else's benchmark (role C): W7163645590, W7164182287, W7170170844, W7151329189, W7165879550, W4417523078, W7167909575, W4402952697, W7202383678, W7139135677, W7127563185, W4406408916, W4405919180, W4407598658. Several read as templated engineering-course or predatory-journal system papers (CASEXPERT, InterviewXpert, LegalEase, GitHub IntelliSolve) that name GPT-4-Turbo only to justify not using it.
- **Prompt only in the authors' own code/GitHub, not the paper.** Nine papers carry the `no_prompt` blocker: the live model was run (or, for W4412945504, its historical outputs were re-scored) and a real number is reported, but the exact prompt text is stated to live only in an external repository or is described purely in prose: W4406071650 (FEAS/COPRA), W7128515724 (Anthropomorphisms), W7165792467 (GitHub IntelliSolve pilot), W4402953864 (stance detection, cites Lei et al.'s prompt), W4412945504 (SkillVerse), W4405425989 (GeoReasoner's summarisation step), W7154655572 (TRUST Agents), W7162044740 (Base-Models-Look-Human fine-tuning), and W7166886536 (GENOME fine-tuning).
- **Data closed or proprietary.** Four papers are blocked by `data_closed`: two Wysa Inc. papers (W7171902763, W7117539811 - near-duplicate companion papers sharing the same anonymized real-user mental-health chat data and proprietary RAG knowledge base), W7166886536 (GENOME's internal newswire corpus, plus an untracked `gpt-5.1` label generator), W7162044740 (a self-constructed paraphrase corpus from an unspecified human source), and W4407911733 (de-identified clinical histories from one hospital, released only "by request").
- **Judge/annotator-only role (A), even when the paper's own point is judge quality.** W4412887898 (fiction-quality judge correlation) and W7168054110 ("Do You Need a Frontier Model as a Citation Verifier?") both study GPT-4-Turbo/GPT-5-mini specifically as evaluators, with real correlation/agreement numbers - but per this project's role taxonomy (S/B required for eligible/maybe) they are marked ineligible with `no_number`, matching precedent from earlier groups (e.g. the DPO winrate judge in W4399447566). W4405425989 (GeoReasoner) is role A as a data-generation component instead.
- **Figure-only numbers.** W4406848657 ("Positioning Political Texts... by Asking and Averaging") is otherwise a model record - exact snapshots (`gpt-4-turbo-2024-04-09`, `gpt-4o-2024-05-13`), a full example prompt, N=899, and even total API cost ("$1.5") are all printed in text - but the actual correlation values sit only in Figures 1/2/5, not as extractable numbers, so it is marked ineligible/`no_number` for consistency with the ACCORD precedent in group 1.
- **Alias resolution.** All `gpt-4-turbo` mentions in this group are undated in text; 26 of 27 resolve to `gpt-4-turbo-2024-04-09` by the post-2024-07-01 date rule (papers ranging from 2024 to 2026), the lone exception being genuinely ambiguous bare `gpt-4` (W4402953864, `unresolved`). `gpt-4.1-nano` mentions (11 papers) resolve directly to `gpt-4.1-nano-2025-04-14` since only one snapshot is tracked for that alias. Two papers pin `gpt-4-turbo-2024-04-09` outright with no rule needed (W4407570954, W4412887898), and two pin `o3-2025-04-16` outright (W4414981059, W7134861441).
- **The 7 eligible papers** span the full model range: W4411120580 (QSpell, `gpt-4-turbo-2024-04-09`, full prompt, 50K-item public test set, high cost), W7169474262 (One-Word Census, cheapest at ~$1/model, self-distinctness avoids needing the full 44-model pool), W4407570954 (Amazon-review documentary sentiment, exact snapshot pinned), W4407386373 (conceptual-combination benchmark, both `gpt-4o-2024-05-13` and `o1-2024-12-17` usable), W4414981059 (scatterplot benchmark, `gpt-4.1-nano-2025-04-14`/`o3-2025-04-16`/`o4-mini-2025-04-16` all pinned exactly), and the two `gpt-5-2025-08-07` biomedical-NLP papers (W7166872551, W7162149911), both with full prompts against standard public corpora.
- **The 11 maybe papers** mostly carry a single soft gap: prompt structure/labels given but exact wrapper text only partial (W7161353709, W7134916521, W7172473915, W7166889477, W7153670014), an undated auxiliary judge used only for ambiguous cases (W7166884145), a questionable per-token-logprobs claim against a chat API (W7166588097), unstated shared-task data distribution (W4403443451), imprecise item counts (W7140953485, W7166889477, W7134861441), or gated academic data (W4402427685's EEG datasets).
