## Observations

- Mention-only hits dominate the ineligible set: 18 of the 31 ineligible papers (14 role C, 4 role A) use the live model only as a citation, benchmark metadata (MT-Bench response sources in W4415308862, X-AlpacaEval references in W4412887910, a release timeline in W4412889103), a documentation URL (W4402427193), a tokenizer (W4407091825), or a judge/annotator/data generator (W7140087450, W4417296658, W4412888618, W7167289877). The bare strings gpt-4-turbo and o3-mini are weak signals of an actual run.
- Seven papers report numbers for a live model but the inputs are produced by a framework rather than a static dataset: games (W4405626302), a chemistry tool runtime (W7131191447), physics simulators (W7140347575), a war/lab simulation (W4412888948), multi-agent coding with discussion (W4412945659), a multi-stage text-to-SQL pipeline (W4409363613) and an AutoML agent (W4414925343). Printed prompts do not make these Tier B; they are marked data_closed with an explanatory note.
- Prompts that live only in a code repository are the sole gap for five papers (RewardBench W4411113083, pun translation W4416102389, UniPrompt W4412944705, AutoML W4414925343, political-science simulation W4404260765). RewardBench and MMLU-Pro-style leaderboard papers have public data and a clean number, so a 'prompt in repo' category would recover some of them if the harness later allows reading code.
- Alias handling: six 2024-2026 papers write GPT-4-turbo without a snapshot (W4411120327, W4412887747, W7140225398, W4405768494, W4414494504, W4404304526) and were resolved to gpt-4-turbo-2024-04-09 by the date rule; W4404389149 names GPT-4-0125 in the main text and gpt-4-turbo-0409 in the appendix (left unresolved); W4402427193 and W4403555729 mix retired preview strings with the live id. The o-series and gpt-4o papers almost always print the full snapshot id.
- Two records are the same experiment (W4411080278 medRxiv and W4415128218 Cureus); run one. Among the eight eligible claims, three are high-cost at three seeds (MMLU-Pro 12K items, SLDS long court decisions with o3-mini, Chumor 3.3K items; MMCode would join them if promoted from maybe); the cheap checks are CEB (100-400 short calls), PLAT (100 cases with o3), the temperature study (1,000 short gpt-4o calls) and the ANCHOR-RE baseline (3.2K cheap gpt-5-mini calls).
- LLM judges were avoided when picking claims: SLDS has a JUDGE column but ROUGE-L was chosen; the legal-reasoning paper's soundness scores come from a GPT-4o auto-evaluator, so accuracy was chosen; JEEM, SEFORA and MirrorAPI use the live model only as the judge or annotator and were excluded by the role rule.
